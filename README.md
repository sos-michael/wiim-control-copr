# Wiim-Control RPMs

Unofficial [Wiim-Control](https://github.com/yocksers/Wiim-Control) packages for Fedora 44 (x86_64).

```sh
sudo dnf copr enable grantson/wiim-control
sudo dnf install wiim-control
```

GitHub Actions checks for upstream releases daily and builds updates in [COPR](https://copr.fedorainfracloud.org/coprs/grantson/wiim-control/).
